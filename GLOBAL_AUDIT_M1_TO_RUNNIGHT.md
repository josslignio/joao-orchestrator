## Blocking P1 findings

### P1-1 — The advertised “full source” archive was incomplete

`FULL_SOURCE_CODE_ALL_M1_TO_RUNNIGHT.zip` contained only `src/`, `tests/` and `scripts/`. It omitted tracked runtime and governance files including `ui.html`, `memory/import_ledger.py`, `memory/ledger_sync.py`, `memory/retro.py`, root configurations and specifications. It therefore could not reproduce the repository independently.

**Correction:** `scripts/build_full_global_audit.py` now packages the complete tracked tree via `git archive`, includes a Git bundle containing history/refs, emits raw gate outputs and refuses to label the package PASS if the complete test suite was skipped or failed.

### P1-2 — Standard pytest collection was broken

The SEC-BOOT canaries executed `sys.exit()` at import time. `pytest tests/` therefore raised an internal collection error even though bounded suites could pass.

**Correction:** canaries are now ordinary pytest tests while remaining executable as standalone diagnostics. CI proves complete collection before running the matrices.

### P1-3 — Run Night task roots were not bound to the repository

A signed but incorrect task specification could point a read-only provider at an arbitrary local directory. Read-only is not sufficient protection for unrelated private files.

**Correction:** every task execution root must resolve to the exact repository root or one of its descendants. Outside roots are rejected before execution.

### P1-4 — Artifact secret detection was narrower than JOÃO’s existing engine

Run Night checked generic labels, AWS IDs and private-key headers but did not reuse the repository’s comprehensive rules for GitHub, OpenAI, Anthropic, Slack and other provider credentials.

**Correction:** Run Night now invokes `SecretsEngine` before persistence and includes regression tests for representative provider-token formats.

### P1-5 — External termination could orphan a Run Night child group

The watchdog killed the process group on its own timeout but did not handle `SIGINT`, `SIGTERM` or `SIGHUP` sent to the watchdog itself.

**Correction:** it now installs signal handlers, terminates the complete process group, escalates to `SIGKILL` after a grace period and has a real subprocess cleanup test.

### P1-6 — Generated bytecode and pytest cache were tracked

The exact source archive contains tracked `__pycache__`, `.pyc` and `.pytest_cache` artifacts. These are machine/version-specific, inflate diffs and undermine clean-clone reproducibility.

**Correction:** the bounded update removes generated caches from version control, extends `.gitignore`, compiles into an external cache directory and verifies a clean worktree afterward.
